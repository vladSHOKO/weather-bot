# Проверки перед выпуском

Проект находится в разработке. Пользователь исключил развёртывание из текущей задачи. Исправления исходного аудита и их проверка описаны в [verification.md](verification.md); этот список относится к будущему рабочему окружению и не означает наличие неисправленных дефектов кода.

- [ ] Создать или подключить полный Git-репозиторий. Перед первым push выполнить `make check-secrets`; при импорте истории проверить её целиком. Запустить подготовленный GitHub Actions workflow. Сейчас история не ведётся, удалённый CI не запускался.
- [ ] Выбрать сервер, Docker context, имя Compose-проекта и хранилище. Проверить роли, владельцев и пароли именно целевой БД, отсутствие её публикации наружу и firewall. Для удалённой БД настроить TLS с проверкой CA и имени.
- [ ] Перед миграцией существующей рабочей БД сделать backup и восстановить его отдельно. Не удалять прежний том и не откатывать миграции при обычной остановке.
- [ ] Настроить ежедневный backup и хранение 14 дней в защищённом хранилище, проверить фактическое выполнение задания и пробное восстановление. Определить политику удаления данных при восстановлении старых копий.
- [ ] Подключить мониторинг readiness, очереди, ошибок и свежести backup по [operations.md](operations.md). Проверить сигналы и адресатов оповещений.
- [ ] Проверить на целевом сервере реальные DNS/HTTPS, условия использования и квоты аккаунтов Open-Meteo/OpenWeather. Живой локальный smoke-тест обоих источников уже выполнен; он не определяет производительность сервера и доступный тариф.
- [ ] Пройти пользовательские команды через настоящую входящую очередь Telegram, затем рестарт приложения; проверить рабочие логи. Текущая приёмка отдельно проверила durable inbox на PostgreSQL и реальные HTTPS-ответы бота/погоды через обработчики с временным хранилищем.
- [ ] Если меняются лимиты, источники или способ развёртывания, повторить соответствующие тесты; не переносить результат локального стенда на новую инфраструктуру автоматически.

Деплой, установка планировщика, настройка внешних оповещений и постоянный запуск приложения в текущей работе не выполнялись.
