# Бесплатные погодные источники

Проверено по официальной документации 19 октября 2026 года. Для прогноза на остаток сегодняшнего дня и весь завтрашний день достаточно бесплатных возможностей. Число сервисов не означает число независимых моделей: провайдеры могут использовать общие исходные данные.

| Сервис | Регистрация | Настройка | Статус в боте |
| --- | --- | --- | --- |
| [Open-Meteo](https://open-meteo.com/) | Не нужна | Нет | Включён всегда |
| [MET Norway](https://docs.api.met.no/) | Не нужна, ключа нет | `MET_NO_USER_AGENT` | Включается при заполнении |
| [WeatherAPI.com](https://www.weatherapi.com/signup.aspx) | Нужен аккаунт Free | `WEATHERAPI_API_KEY` | Включается при заполнении |
| [OpenWeather](https://home.openweathermap.org/users/sign_up) | Нужен аккаунт и ключ | `OPENWEATHER_API_KEY` | Ранее реализованное необязательное подключение |

## WeatherAPI.com: где зарегистрироваться

1. Создать аккаунт на [странице регистрации](https://www.weatherapi.com/signup.aspx).
2. Выбрать постоянный **Free**: 100 000 запросов в месяц, прогноз на 3 дня, почасовые данные. Регистрация не требует карты. Код использует `forecast.json` с `days=2`, без платных дополнительных данных. См. [тарифы](https://www.weatherapi.com/pricing.aspx) и [документацию](https://www.weatherapi.com/docs/forecast-api/).
3. Скопировать API key из кабинета в `.env`:

```dotenv
WEATHERAPI_API_KEY=ваш_ключ
```

По [условиям тарифа](https://www.weatherapi.com/pricing.aspx) при исчерпании месячной квоты Free выдача данных прекращается до сброса квоты; платный тариф для работы бота не требуется. В таком случае бот покажет недоступность WeatherAPI и использует оставшиеся источники.

## MET Norway: без регистрации

API бесплатно, аутентификации и API key нет. Вместо ключа требуется идентификация приложения с действительным email владельца или URL сайта/проекта, где можно найти контакт. Пример формата ниже нужно заменить своим контактом:

```dotenv
MET_NO_USER_AGENT="weather-sum/1.0 owner@your-domain.org"
```

Допускается `weather-sum/1.0 https://your-domain.org/contact`. Пустая настройка отключает источник. Не используйте вымышленные контакты: это нарушает [правила API](https://docs.api.met.no/doc/TermsOfService).

Запросы идут на `https://api.met.no/weatherapi/locationforecast/2.0/compact`. Координаты ограничены четырьмя знаками после запятой; соблюдаются `Expires`, `Last-Modified`, `If-Modified-Since`, `Retry-After`. Кеш ограничен `CACHE_CAPACITY`; свежие записи не вытесняются до `Expires`. Данные CC BY 4.0: в отчёте есть источник, ссылка на лицензию и пометка о расчёте сводки ботом. Глобальный прогноз описан в [модели данных](https://docs.api.met.no/doc/locationforecast/datamodel.html).

## Open-Meteo и OpenWeather

Open-Meteo уже работает без регистрации. Его бесплатный публичный API предназначен для некоммерческого использования, с лимитами 600 запросов в минуту, 5 000 в час, 10 000 в сутки и 300 000 в месяц; см. [условия](https://open-meteo.com/en/terms). Это относится и к развитию текущего бота: бесплатный публичный доступ не следует считать безлимитным.

Для существующего адаптера OpenWeather нужен ключ из [кабинета](https://home.openweathermap.org/api_keys), настройка `OPENWEATHER_API_KEY`. Он вызывает только [5 day / 3 hour forecast](https://openweathermap.org/api/forecast5), а не One Call. Перед включением убедитесь, что этот endpoint доступен бесплатно в вашем аккаунте: на публичной [странице тарифов](https://openweathermap.org/price) условия One Call и других подписок различаются. Для новых подключений достаточно WeatherAPI.com и MET Norway; OpenWeather можно оставить пустым.

## Применение настроек и проверка

После заполнения `.env` перезапустить процесс бота. При Docker-развёртывании пересоздать сервис с новыми переменными:

```bash
docker compose -f compose.deploy.yml up -d --build bot
```

`.env` остаётся локальным файлом с правами `600`; ключи не нужны в исходниках. В ответе на «Погода» появится компактная подпись доступных источников. Состояния `WeatherAPI.com` и/или `MET Norway` видны по кнопке «Подробнее». Без настроек они не попадают в список и не вызываются.

Источник с ошибкой не блокирует сводку, если есть пригодные данные других сервисов. Нулевая температура и нулевые осадки сохраняются как значения; отсутствие поля остаётся неизвестным. Все интервалы в сообщении отображаются в часовом поясе выбранного города. Ни счётчик доступных сервисов, ни доля согласных прогнозов не выдаются за вероятность осадков.

Автоматические проверки используют синтетические ключи и HTTPS-заглушки, включая запуск приложения с тремя источниками. Проверка настоящего WeatherAPI возможна после добавления владельцем рабочего ключа.
