# Raincheck Bot Project Plan

План исправлений по результатам аудита: [REMEDIATION_PLAN.md](REMEDIATION_PLAN.md). Он содержит отдельные блоки стабилизации и критерии их готовности; завершённые ниже этапы MVP не означают закрытия замечаний аудита.

План разработки MVP Telegram-бота, который получает прогнозы погоды из нескольких сервисов, собирает сводку и помогает понять, нужен ли зонт.

Основной принцип работы над проектом: делаем один этап, проверяем реализацию, вносим корректировки и только потом переходим к следующему этапу.

## Текущая итерация стабилизации

19 октября 2026, итерация 4: **аудит закрыт для стадии разработки**. Выполнены регрессии, изолированные стенды, сканирование секретов/зависимостей и живой smoke @weatherAggregateBot с обоими погодными источниками. Слабый пароль администратора реальной локальной БД заменён после backup и пробного восстановления; БД оставлена остановленной. Пользователь подтвердил отсутствие Git-истории и исключил деплой. Этапы MVP 15–16 выполнены; будущая рабочая приёмка вынесена в [список перед выпуском](docs/release-checklist.md). Результат — в конце [плана исправлений](REMEDIATION_PLAN.md).
